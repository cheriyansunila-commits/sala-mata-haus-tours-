# Sala Mata Haus & Tours

## Overview
Sala Mata Haus & Tours is a fully responsive multi-page web application designed to promote regional hospitality, accommodation options, and guided tourism experiences.

## Features
- **Multi-Page Layout:** Includes Home, About, Services, Tours, Gallery, and Contact pages.
- **Responsive Design:** Built with CSS3 Flexbox and custom media queries to seamlessly adapt to mobile, tablet, and desktop viewports.
- **Interactive Forms:** Features a clean, user-friendly contact form for customer inquiries.
- **Visual Showcase:** Integrated image galleries highlighting local attractions and accommodations.

## Technologies Used
- Semantic HTML5
- CSS3 (Flexbox, Media Queries)
- Git & GitHub Pages
